# 🎉 Eventify - Full Stack Event Booking System

## 📖 Overview

Eventify is a production-style full stack Event Booking System built to learn and practice modern web development.

## 🚀 Tech Stack

### Frontend
- React (Vite)
- React Router
- Tailwind CSS
- Axios
- React Hook Form
- React Hot Toast

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Multer
- Cloudinary
